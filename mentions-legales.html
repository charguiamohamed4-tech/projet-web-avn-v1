Mentions légales

GameHub est un projet pédagogique réalisé dans le cadre de l’activité « Programmation Web avancée — CSS3 ».

Édition du site

Cette version est une démonstration frontend. Le nom légal de l’éditeur, son adresse et les éventuelles coordonnées de publication n’ont pas été fournis dans les éléments du projet. Ces informations doivent être ajoutées par le responsable du site avant toute publication réelle.

Hébergement

Le site est fourni sous la forme d’un dossier de fichiers HTML, CSS, JavaScript et médias. Aucun hébergeur n’est renseigné dans la version remise.

Contenus et médias

Les noms, descriptions, jaquettes, vidéos et bandes-son de ce projet servent de contenu de démonstration. Les médias audio et vidéo fournis sont des fichiers de test et ne sont pas présentés comme des extraits officiels de jeux commerciaux.

Note : cette page est une base informative pour le projet scolaire, et non un avis juridique ni une déclaration de conformité légale d’un site mis en production.
