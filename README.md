# GameHub

Site frontend pédagogique en HTML, CSS et JavaScript. Aucune installation ni dépendance externe n’est nécessaire.

## Lancer le projet

1. Décompresser le dossier `gamehub`.
2. Ouvrir `index.html` dans un navigateur récent.
3. Pour tester les vidéos, l’audio et le stockage local, autoriser la lecture des médias dans le navigateur. Si le navigateur limite les médias lors d’une ouverture en `file://`, lancer un serveur statique local (par exemple avec l’extension Live Server de VS Code).

Les pages de détail sont `jeu1.html` à `jeu6.html`. Les pages d’information sont `mentions-legales.html`, `politique-confidentialite.html` et `contact.html`. Les contenus et médias sont démonstratifs.
